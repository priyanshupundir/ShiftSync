# ShiftSync

ShiftSync is a full-stack Shift Handover and Incident Management SaaS platform designed to help operational teams manage shift transitions, incidents, tasks and team communication.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- React Router
- React Hook Form
- Zod
- Recharts
- Socket.IO Client

### Backend
- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- Socket.IO
- JWT
- bcrypt

## Project Structure

- `client/` — React frontend
- `server/` — Express backend
- `docs/` — Architecture and technical documentation

## Local Development

Frontend:

```bash
cd client
npm install
npm run dev
```

Backend:

```bash
cd server
npm install
npm run dev
```
